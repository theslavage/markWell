# AI Context Prompt — MarkWell

Используй этот файл как стартовый контекст в каждом новом чате по проекту MarkWell.

## Роль пользователя

Пользователь работает в MarkWell на позиции арт-директора. Задачи: графика, сайт, визуальная система, упаковка/брошюры, презентации, контент и бренд-коммуникация.

## Компания

MarkWell — бренд оборудования для мастеров маникюра и педикюра. Текущий основной продукт: вытяжка MarkWell / MW One для контроля пыли и чистоты рабочего места.

## Главная идея бренда

MarkWell продаёт не просто вытяжку. MarkWell продаёт новый стандарт рабочего пространства мастера: чистота, здоровье, комфорт, контроль, технологичность, эстетика и системный подход.

## Позиционирование

Премиальный технологичный clean/tech бренд для nail-индустрии. По ощущению ориентиры: BORK, Dyson, Apple. Не копировать буквально, а брать уровень: чистота, инженерность, спокойная уверенность, высокая визуальная дисциплина.

## Ключевая UX-формула сайта

Сначала эмоция → потом доверие → потом покупка.

Сайт не должен ощущаться как обычный магазин. Он должен ощущаться как презентация технологичного продукта, где покупка становится логичным финалом.

## Визуальный код

- тёмно-синий / графитовый / глубокий чёрный фон;
- мягкое голубое свечение;
- 3D-рендеры продукта;
- воздушные потоки, частицы пыли, фильтрация;
- много воздуха;
- минимум текста;
- крупная типографика;
- аккуратные карточки;
- soft glow;
- премиальная, спокойная анимация;
- никаких дешёвых маркетплейсных визуалов.

## Тон коммуникации

Спокойно, уверенно, технологично, профессионально. Через пользу, а не через сухие характеристики.

Плохо: `41 Вт, 10 режимов`.
Хорошо: `Пыль не успевает подняться — она сразу уходит внутрь вытяжки`.
