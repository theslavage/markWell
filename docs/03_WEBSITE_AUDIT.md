# 03. Website Audit

## Текущий сайт

Сайт: `https://markwell.online/`

Текущая задача сайта — продавать оборудование MarkWell, но дальнейшая цель проекта — перевести сайт из ощущения обычного магазина в ощущение премиальной презентации технологичного продукта.

## Главная UX-логика из ТЗ

Сайт не должен ощущаться как «магазин».

Он должен ощущаться как:

- презентация технологичного продукта;
- брендовая история о чистоте, здоровье и контроле;
- пространство доверия;
- место, где покупка становится логичным финалом.

Формула:

**эмоция → доверие → покупка**

## Что нужно усилить

### 1. Первый экран

Нужен hero, который сразу создаёт ощущение технологичного бренда:

- крупная 3D-вытяжка MarkWell MW One;
- тёмно-синий / графитовый фон;
- воздушные потоки;
- частицы пыли;
- мягкое голубое свечение;
- короткий сильный заголовок.

Ключевой текст:

> Чистый воздух. Новый стандарт работы мастера.  
> Здоровье важнее компромиссов.

### 2. Блок «Как это работает»

Один из главных блоков доверия.

Формат:

- 3D-разборка вытяжки;
- корпус;
- вентилятор;
- фильтр;
- поток воздуха;
- подсветка;
- крепления.

Задача: показать инженерность и отделить MarkWell от дешёвых аналогов.

### 3. Преимущества через пользу

Не писать сухо: `41 Вт, 10 режимов`.

Писать через ощущение и результат:

- Пыль не успевает подняться — она сразу уходит внутрь вытяжки.
- Регулируйте мощность под каждый этап процедуры.
- Подсветка помогает сохранять визуальный комфорт.
- Удобная смена фильтра на магните.
- Надёжная фиксация на кронштейн или стойку.

### 4. Проблема → Решение

Блок должен показать разницу, но без дешёвого страха.

Без MarkWell:

- пыль в воздухе;
- загрязнённая поверхность;
- хаос;
- усталость.

С MarkWell:

- чистая поверхность;
- контроль пыли;
- эстетичный сетап;
- спокойная работа.

### 5. Каталог

Каталог не должен быть простой лентой товаров.

Нужна логика: **как WB по понятности, но как BORK по визуальному уровню**.

Разделы:

- Вытяжки
- Аксессуары
- Расходники
- Комплекты
- Система рабочего места

Важно: не уводить сразу на WB/Ozon. Сначала изучение продукта, quick view, преимущества, потом покупка.

### 6. Поддержка

Раздел должен быть не просто FAQ, а support center tech-бренда:

- инструкции;
- замена фильтра;
- гарантия;
- сервис;
- документы;
- сертификаты;
- FAQ;
- контакт с поддержкой.

## Главная рекомендация

Сайт должен стать не «витриной товаров», а **продуктовым бренд-лендингом с каталогом**, где каждый блок усиливает ощущение системы, технологии и премиального рабочего пространства.
