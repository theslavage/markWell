# 02. Visual System

## Общий стиль

Премиальный технологичный clean/tech стиль для оборудования nail-индустрии.

Ощущение: BORK / Dyson / Apple, но адаптировано под MarkWell и рабочее место мастера.

## Цветовая база

- глубокий тёмно-синий
- графитовый
- чёрный
- холодный белый
- мягкий серый
- акцент: голубое свечение / airflow blue

## Визуальные мотивы

- 3D-рендер вытяжки
- exploded view / разборка продукта на слои
- воздушные потоки
- частицы пыли
- мягкое свечение
- чистые рабочие поверхности
- аккуратный nail-сетап
- фильтр, подсветка, крепления, стойка

## Композиция

- много воздуха
- минимум текста
- крупный продукт в кадре
- тёмные технологичные фоны
- карточки с закруглениями
- soft glow при наведении
- clean grid
- строгая типографика

## Анимации

Использовать:

- плавное появление продукта
- движение частиц к вытяжке
- мягкие потоки воздуха
- scroll-telling
- exploded view
- fade-up
- лёгкий zoom карточек
- hover glow

Не использовать:

- резкие эффекты
- прыгающие элементы
- кислотные цвета
- дешёвые UI-эффекты
- перегруженные иконки

## Фотостиль

Нужны:

- чистые рабочие места
- аккуратные студии
- мастера в процессе работы
- педикюр и интенсивный опил
- крупные планы продукта
- фильтр / подсветка / регуляторы / крепления
- реальные рабочие места для отзывов

Избегать:

- грязных пугающих кадров
- дешёвого сравнения «до/после»
- чрезмерного медицинского страха
- маркетплейсного хаоса

## Рендеры

Приоритет: 3D-рендеры вытяжки MW One и аксессуаров.

Ключевые сцены:

1. Hero: продукт в центре, тёмный фон, голубой поток воздуха.
2. Как работает: вытяжка разбирается по слоям.
3. Преимущества: карточки с деталями продукта.
4. Каталог: продукты как единая система рабочего места.
5. Технология: фильтрация, аэродинамика, поток, подсветка.
6. Брошюра: чистые предметные рендеры с большим количеством воздуха.
