### 2. Как работает MarkWell

Заголовок:

> Как работает MarkWell

Суть:

Вытяжка спроектирована так, чтобы захватывать пыль в момент её появления и удерживать её внутри системы фильтрации.

Элементы:

- корпус;
- вентилятор;
- фильтр;
- поток воздуха;
- подсветка;
- крепления.

### 3. Преимущества

- Мощность
- Контроль
- Свет
- Комфорт и удобство
- Надёжность

Подавать через пользу, а не через сухие характеристики.

### 4. Проблема → Решение

Слева: без вытяжки.  
Справа: с MarkWell.

Эмоция:

- хаос / пыль / усталость;
- чистота / контроль / эстетика / комфорт.
