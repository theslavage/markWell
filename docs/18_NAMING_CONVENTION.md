# 18. Naming Convention

Дата: 2026-05-24

## Каноническое написание бренда

Бренд всегда пишем слитно:

```txt
MarkWell
```

## Неправильное написание

Не использовать:

```txt
Mark Well
```

## Где применять

Каноническое написание `MarkWell` использовать везде:

- сайт Framer;
- header / footer;
- hero-блоки;
- CTA;
- FAQ;
- юридические страницы;
- политика конфиденциальности;
- условия сервиса;
- карточки товара;
- презентации;
- брошюры;
- тексты для маркетплейсов;
- GitHub-документы;
- промпты для генерации графики и видео.

## Правило для AI

Если в старых документах встречается `Mark Well`, считать это устаревшим написанием и автоматически заменять на `MarkWell` в новых текстах.

При подготовке новых материалов всегда использовать только `MarkWell`.
