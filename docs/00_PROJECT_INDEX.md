# 00. Project Index

## Компания

MarkWell — бренд оборудования и аксессуаров для мастеров маникюра и педикюра.

Основной продукт сейчас: вытяжка MarkWell / MW One для контроля пыли и чистоты рабочего места.

## Роль пользователя

Пользователь устроился в MarkWell на позицию арт-директора.

Зона ответственности:

- визуальная система бренда
- сайт и посадочные страницы
- графика
- презентации
- брошюры
- упаковка / инструкции
- продуктовая коммуникация
- контент для соцсетей и маркетплейсов
- постановка задач дизайнерам, разработчикам и подрядчикам

## Главная коммуникационная идея

MarkWell продаёт не просто вытяжку.

MarkWell продаёт **новый стандарт рабочего пространства мастера**:

- чистый воздух
- контроль пыли
- комфорт
- здоровье
- эстетика
- технологичность
- порядок на рабочем месте
- системный подход к оборудованию

## Главный брендовый вектор

Из обычного магазина оборудования нужно перейти в ощущение premium tech product presentation.

Референсное ощущение:

- BORK
- Dyson
- Apple

## Приоритеты

1. Зафиксировать брендовый фундамент.
2. Пересобрать сайт как премиальную технологичную презентацию продукта.
3. Сформировать дизайн-систему.
4. Упаковать MW One через storytelling.
5. Подготовить брошюру и инструкции.
6. Создать библиотеку ассетов и понятный asset pipeline.
