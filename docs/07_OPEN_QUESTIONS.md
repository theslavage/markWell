# 07. Open Questions

Этот файл хранит открытые вопросы по проекту MarkWell. После уточнения решений переносить их в соответствующие документы и фиксировать в `docs/CHANGELOG_CONTEXT.md`.

## Бренд и стратегия

- Финальное позиционирование: MarkWell как бренд оборудования или как система рабочего пространства?
- Нужен ли отдельный слоган бренда помимо `Чистый воздух. Новый стандарт работы мастера`?
- Какие смыслы можно использовать про здоровье юридически безопасно?
- Какие формулировки нельзя использовать без медицинских/лабораторных доказательств?

## Продукт

- Финальное название продукта: MarkWell, MW One или MarkWell MW One?
- Есть ли точные технические характеристики для публичного использования?
- Какие сертификаты можно показывать на сайте?
- Какие гарантии и условия сервиса подтверждены официально?
- Какой срок службы фильтра при разных сценариях работы?

## Сайт

- Какой движок/технология будет использоваться для нового сайта?
- Нужна ли корзина на сайте или покупка только через маркетплейсы?
- Какие страницы обязательны для первого релиза?
- Какие разделы можно вынести во второй этап?
- Нужно ли делать личный кабинет?
- Нужен ли полноценный блог / база знаний?

## Каталог

- Какие товары уже доступны к продаже?
- Какие товары только планируются?
- Какие цены финальные?
- Будут ли комплекты?
- Нужен ли конфигуратор подбора комплекта?

## Визуал

- Есть ли исходные 3D-модели вытяжки?
- Есть ли брендовые шрифты?
- Есть ли утверждённый логотип в векторе?
- Есть ли исходники фото/видео с мастерами?

## Брошюра

- Будут ли разные версии брошюры для покупателей, партнёров и мероприятий?
- Нужна ли инструкция внутри брошюры или отдельный вкладыш?
